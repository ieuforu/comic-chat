Community Rules

这是公开聊天室：你发送的文字、图片、显示名，以及在线状态，都会被其他访问者看到。 请不要把这里当成私密空间。

不要发送任何违法内容，包括儿童性剥削内容、暴恐、诈骗、恶意软件、仇恨与骚扰、 人肉搜索、他人隐私或未经同意的私密影像。发现即删除，并可能直接关闭整个站点。

1. 可以做什么

  • 聊天、发图片、讨论技术或日常，保持基本的尊重。
  • 用 Ctrl+V 粘贴 PNG / JPEG / GIF / WebP 图片，单张不超过 3 MB。
  • 对规则或删除有异议，可以通过下方联系方式申诉。

2. 不要做什么

  • 不要发广告、刷屏、重复粘贴、恶意 @ 或绕过频控。
  • 不要冒充他人，包括伪造显示名、头像或会话身份。
  • 不要上传恶意文件、探测/攻击服务、尝试获取他人会话或管理权限。
  • 不要发布他人的姓名、电话、住址、身份证件、工作单位等隐私信息。
  • 不要发布 NSFW、血腥、虐待动物或其他不适合公开场所的内容。

3. 消息、图片与保留期

  • 聊天文字最多保留最近 2000 条；更早的消息会被清理。
  • 图片默认保留 72 小时，到期自动删除；但可能因运营需要提前删除。
  • 运营者可以删除任意消息和关联图片；删除后在线页面会同步移除。
  • 服务可能随时维护、限流、关闭；不要依赖它保存重要内容。

4. 身份与隐私

  • 没有账号系统。身份由服务端签发的 sid cookie 决定，有效期 180 天。
  • 昵称和头像由服务端派生，客户端不能任意修改；运营者可以调整显示名。
  • 清除 cookie、换浏览器或换设备会变成一个新身份。
  • 消息、图片和必要的运行日志保存在服务器；反向代理可能记录 IP 与时间。
  • 本站不做广告追踪；请勿在公开消息里填写敏感个人信息。

5. 举报与处理

  • 举报请提供消息序号、时间、截图或页面链接。
  • 可以通过 GitHub @ieuforu 或仓库 Issues 联系运营者；涉及敏感内容时请先只发“需要私下联系”。
  • 运营者可以删除内容、限制访问或直接停止服务，且不保证提前通知。

6. 未成年人

不建议未成年人使用本公开聊天室。若发现涉及未成年人的不当内容，将立即删除并保留 必要记录，必要时向平台或执法机构报告。

English summary: This is a public chat. Do not post illegal, sexual, violent, hateful, harassing, or private content. Images are limited to 3 MB and kept for about 72 hours. Messages may be deleted and the service may be closed at any time. Report abuse via GitHub @ieuforu.
